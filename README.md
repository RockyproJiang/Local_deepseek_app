# AI Chat Assistant

一个基于Ollama和DeepSeek模型的本地AI聊天助手应用，具有对话记忆和流式输出功能。

## 功能特点

- 💬 实时对话，支持流式输出
- 🧠 对话记忆管理，每个会话独立存储
- 📝 查看和清空对话记忆
- 🎨 美观的macOS风格界面
- 🔄 多对话管理，支持切换和新建
- ⏸️ 停止生成功能
- 💾 自动保存对话历史

## 系统要求

- Python 3.7+
- [Ollama](https://ollama.ai/) 已安装并运行
- DeepSeek模型已下载
